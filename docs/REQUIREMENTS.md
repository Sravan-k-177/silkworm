# Requirement coverage

The supplied challenge remains the acceptance scope. This matrix separates implemented behavior from scientific validation and deployment evidence. Passing workflow tests does not prove predictive accuracy.

| Requirement | Current evidence | Remaining work |
|---|---|---|
| Smartphone images | Local image decoding, resize, metadata stripping, thumbnail and IndexedDB storage | Real phone/camera tests across shed conditions |
| Short videos | Up to five sampled frames, brightness/clarity and raw frame difference | Real-device codec testing and validated activity features; synthetic VP9 browser workflow passes |
| Larval AI visual assessment | Trained MobileNetV3 from audited image groups; complete ONNX network deployed on backend and browser; inference can be attached to batch assessments | Independent farm and Andhra Pradesh data; frozen external evaluator and leakage checks implemented, evaluation pending data |
| Mulberry field photos | Separate leaf capture, offline classifier, quality/confirmation gates, saved model evidence and feed-review factor; leaf and tray images remain separate | Independent field evaluation; residues, contamination and nutritional quality cannot be established from photos |
| Environmental inputs | Temperature, RH, ventilation and hygiene fields; instar-aware reference rules | Local approved SOP, sensor calibration and exposure histories |
| Low/medium/high risk | Explicit capped priority rules and explanatory factor list | Prospective outcome-trained model and validated thresholds |
| Confidence | Separate internal calibration split, score-based abstention and photo-quality retake checks | Field calibration and unsupported-object evaluation |
| Visual cues | Real larval and leaf occlusion tests; browser/backend larval explanation parity | Expert explanation review and independent field evaluation |
| High-risk flags | Durable per-assessment alerts, staff-code acknowledgement, scheduling, live overdue state, resolution/reopening and history | Authenticated submission receipts implemented in account mode; notification delivery and field validation remain |
| Preventive actions | Checklist actions and source-linked regional environmental guidance | Departmental validation, breed/locale version management |
| Offline capture | Complete field workflow passes in offline Chromium | Storage pressure, interruption, mobile OS eviction and installation tests |
| Deferred sync | Local queue, SQLite service, idempotency and conflict rejection | Account/farm and parent-reference checks implemented; field network trials remain |
| Lightweight app | Production bundle and small offline leaf model | Representative Android latency, memory, battery and download measurements |
| Batch monitoring | Batch IDs, instar histories, care logs and outcome records | Explicit cycle closure, transfers and field validation of recorded denominator scope |
| Supervisor dashboard | Farm/risk/latest-assessment UTC date filters, priority list, descriptive trends, risk-before-outcome table | Calibrated prospective comparisons and visit assignment |
| Traceability | Immutable events, assessment-linked review/correction notes, export/import | Authenticated submitter receipt implemented; actual observer identity/diagnoses remain self-reported; formal audit policy pending |
| ERR, cocoon yield, shell quality | Raw counts/weights, harvest date, count scope, sample count and derived ratios; missing values preserved | Field validation of cohort/sample definitions and independently verified event times |
| Multilingual/accessibility | English/Telugu UI and bundled font; language persistence and draft preservation; responsive widths 320–1440 px | Independent Telugu/SOP review and farmer usability study |
| Privacy/security | Account sessions, hashed passwords, role/farm authorization, separate device workspaces, origin checks, optional demo token | Caddy HTTPS configuration validated; real host/domain activation, operator retention policy and deployment review remain |
| Scalability | Local proof of workflow; tested SQLite backup and restored-copy integrity | Multi-site infrastructure, load testing, monitoring and recovery |
| Research deliverable | Evolving cited paper/dataset/project audit | Printable HTML/PDF report and curated CSV/JSON inventory implemented; unresolved-method audits remain |

Event timestamps describe recording time; separate harvest dates and health observation/onset times can be recorded, with onset precision retained. Comparing an earlier assessment with an outcome entry does not establish that the assessment preceded disease onset or harvest. Future accuracy studies need independently verified event times and partitions by batch, farm and acquisition family.
